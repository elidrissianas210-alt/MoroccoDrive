# MVP Definition

## Objective

Launch the first production-ready version of the platform for the Moroccan market and onboard the first paying agencies.

---

# Target Users

- Customers
- Rental Agencies
- Platform Administrator

---

# V1 Features

## Public Marketplace

- Landing Page
- Search Cars
- Search Results
- Car Details
- Agency Profile
- About
- Contact
- FAQ

---

## Authentication

- Customer Register
- Customer Login
- Agency Register
- Forgot Password
- Reset Password
- Email Verification

---

## Customer

- Dashboard
- My Bookings
- Booking Details
- Profile
- Settings

- Dashboard

# NOT Included in V1

- Mobile App
- AI Recommendations
- Reviews & Ratings
- Employee Management
- Loyalty Program
- Coupons
- Multi-language
- Multiple Currencies
- Live Chat
- Insurance Marketplace
- Driver Marketplace
- Public API

---

# Success Criteria

- First agency registered
- First paid subscription
- First successful booking
- Stable production release
