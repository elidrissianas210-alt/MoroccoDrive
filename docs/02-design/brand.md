# Brand Identity

## Brand Position

A premium SaaS marketplace connecting customers with verified car rental agencies across Morocco.

The platform combines a modern marketplace with powerful agency management software.

---

# Brand Personality

The product should always feel:

- Premium
- Trustworthy
- Professional
- Modern
- Elegant
- Minimal
- Fast
- Secure
- Scalable

---

# Design Principles

- Simplicity first
- Function over decoration
- Premium spacing
- High readability
- Clear hierarchy
- Consistent components
- Mobile-first
- Accessibility first

---

# Visual Direction

The interface should feel similar in quality to products like:

- Stripe
- Linear
- Vercel
- Notion

Do NOT copy any existing product.

Create a unique identity.

---

# Color Philosophy

Use neutral colors as the foundation.

Use one premium accent color.

Avoid using many bright colors.

Colors should communicate trust and professionalism.

---

# Typography

Modern sans-serif typography.

Large headings.

Comfortable reading.

Strong hierarchy.

---

# Components

Every component must be reusable.

No page should introduce new styles that don't exist in the design system.

---

# UX Philosophy

Reduce friction.

Reduce clicks.

Guide the user.

Always make the next action obvious.

---

# Dashboard Philosophy

Dashboards should prioritize information.

No unnecessary widgets.

No visual noise.

Every chart must help decision making.

---

# Marketplace Philosophy

Customers should be able to:

- Search quickly.
- Compare easily.
- Trust the agencies.
- Complete bookings with confidence.

---

# Agency Experience

Agencies should feel that this platform replaces multiple tools.

One dashboard.

One workflow.

One subscription.

---

# Scalability

Every screen must support future features without redesigning the product.
