# Search Component

## Purpose

The Search Component is the entry point of the MoroccoDrive marketplace.

Its goal is to help users find the right vehicle with the fewest possible interactions.

---

## Used In

- Landing Page
- Search Results
- Mobile Search
- Future Mobile App

---

## Fields

- Pickup City
- Pickup Date
- Pickup Time
- Return Date
- Return Time
- Vehicle Category (Optional)
- Driver Age (Optional)

---

## Actions

Primary

- Search Cars

Secondary

- Swap Locations (future)

---

## Validation

Pickup date cannot be in the past.

Return date must be after pickup.

Pickup time is required.

Return time is required.

---

## Business Rules

Always remember the user's last search.

Support popular Moroccan cities.

Prioritize instant booking vehicles.

---

## Responsive Behavior

Desktop

Horizontal Search Bar

Tablet

Two Rows

Mobile

Bottom Sheet Search

---

## Accessibility

Keyboard navigation

Large touch targets

Visible focus
