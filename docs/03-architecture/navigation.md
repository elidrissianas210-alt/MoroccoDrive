## Navigation Principles

- Maximum 7 main sidebar items before grouping.
- Every page must be reachable within 3 clicks.
- Always highlight the active page.
- Breadcrumbs for nested pages.
- Mobile navigation must be optimized separately.
- Primary CTA must always be visible.
- Navigation should remain consistent across the platform.
