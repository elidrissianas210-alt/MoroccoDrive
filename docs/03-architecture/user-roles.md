# User Roles & Permissions

## Overview

The platform has three primary roles:

1. Guest
2. Customer
3. Agency Owner
4. Platform Administrator

---

# Guest

Description

A visitor who is not authenticated.

Permissions

- View Landing Page
- Search Cars
- View Search Results
- View Car Details
- View Agency Profile
- View Pricing
- Contact Support
- Register
- Login

Restrictions

- Cannot create bookings
- Cannot access dashboards
- Cannot contact agencies directly

---

# Customer

Description

A registered customer looking to rent vehicles.

Permissions

- Search Cars
- Book Cars
- View Bookings
- Cancel Booking (according to policy)
- Download Contracts
- Manage Profile
- Save Favorite Cars
- Receive Notifications

Restrictions

- Cannot manage cars
- Cannot access agency dashboard
- Cannot manage agencies

---

# Agency Owner

Description

Business owner managing one rental agency.

Permissions

- Manage Agency Profile
- Manage Cars
- Upload Images
- Manage Availability
- Accept or Reject Requests
- Manage Instant Bookings
- Manage Customers
- Generate Contracts
- View Analytics
- Manage Subscription
- Manage Employees (Future)
- Configure Booking Mode
- Configure Pickup Locations

Restrictions

- Cannot manage other agencies
- Cannot access platform administration

---

# Platform Administrator

Description

Platform owner.

Permissions

- Manage Agencies
- Approve Agencies (optional)
- Suspend Agencies
- Manage Cars
- Manage Users
- Manage Bookings
- Manage Contracts
- Manage Subscriptions
- Manage Payments
- Manage Reports
- Manage CMS
- View Platform Analytics

Restrictions

None.
