# MoroccoDrive

MoroccoDrive is a modern SaaS marketplace connecting car rental agencies and customers across Morocco.

## Current Technology

- Next.js
- TypeScript
- Tailwind CSS
- Docker
- GitHub Actions

The documented architecture plans integrations with Supabase, Drizzle ORM, and Stripe; those integrations are not implemented in the current application foundation.

## Documentation

Project documentation is located in the `/docs` directory.

All contributors and AI agents must read:

- AGENTS.md
- /docs

before making any changes.
